---
title: "Webhook events"
description: "What AdsEra posts to your URL for each event, field by field."
---

Add webhooks in [**Settings → Webhooks**](https://app.adsera.in/setting/webhooks): your URL, the events you want, and for message events the WhatsApp numbers to watch.

## Delivery

- **Request:** a `POST` with `Content-Type: application/json` and the body `{ "event", "timestamp", "data" }`.
- **Checking the sender:** if you set a **secret**, it arrives in the `x-secret` header; compare it to yours. You can also add Basic, Bearer or custom-header authentication on the webhook.
- **Answering:** reply with any `2xx` within 5 seconds. Failed deliveries are not retried.
- **URLs:** must be public `https://` addresses. Private and local addresses are refused.

## message.new

A customer sent a message.

```json
{
  "event": "message.new",
  "timestamp": "2026-11-20T10:14:55.000Z",
  "data": {
    "_id": "6740a1…",
    "messageId": "wamid.HBgM…",
    "direction": "inbound",
    "type": "text",
    "text": { "body": "Hi, what's the price?" },
    "preview": "Hi, what's the price?",
    "contact": "919876543210",
    "name": "Priya",
    "from": "919800000000",
    "wabaId": "68a0…",
    "timestamp": "2026-11-20T10:14:54.000Z"
  }
}
```

| Field | Meaning |
| --- | --- |
| `preview` | The message as text. Media shows as `[Image: caption]`, a voice note as `[Voice note]`, a button tap as its text. |
| `contact` / `name` | The customer's phone and first name. |
| `from` | Your WhatsApp number that received it. |
| `type` and its object (`text`, `image`, `interactive`…) | The raw WhatsApp message, if you need more than the preview. |

## message.sent

AdsEra sent a message: the AI agent's reply, your team's reply, a template, a campaign, a sequence or a follow-up. This is a separate event from `message.new`, so a system that answers incoming messages never answers its own.

```json
{
  "event": "message.sent",
  "data": {
    "_id": "6740a2…",
    "messageId": "wamid.HBgM…",
    "direction": "outbound",
    "type": "text",
    "preview": "Hi Priya! It's ₹999 a month. Shall I book a quick demo?",
    "sentBy": "AI",
    "source": "addy",
    "status": "sent",
    "contact": "919876543210",
    "from": "919800000000",
    "wabaId": "68a0…"
  }
}
```

| Field | Meaning |
| --- | --- |
| `sentBy` | `AI`, `Team`, `Team (WhatsApp app)`, `Broadcast (bulk campaign)` or `Automation (sequence)`. |
| `preview` | What the customer saw. A template comes as `[Template "name"] text with the values filled in`. |
| `templateName` | The template's name, for template messages. |
| `campaign` | The campaign id, for campaign messages. |

## message.status_updated

A message you sent was sent, delivered, read or failed.

```json
{
  "event": "message.status_updated",
  "data": { "messageId": "wamid.HBgM…", "status": "read", "timestamp": "2026-11-20T10:16:10.000Z", "messageErrors": null, "wabaId": "68a0…" }
}
```

Match `messageId` to the `messageId` of the `message.sent` event. When `status` is `failed`, `messageErrors` holds WhatsApp's reason.

## call.ended

A WhatsApp call finished, was missed or was rejected. This covers every call: answered by the AI voice agent, by your team, or by your own system.

```json
{
  "event": "call.ended",
  "data": {
    "id": "6740b3…",
    "callId": "wacid.HBgM…",
    "contact": "919876543210",
    "direction": "inbound",
    "status": "END",
    "handledBy": "ai",
    "startedAt": "2026-11-20T11:02:10.000Z",
    "endedAt": "2026-11-20T11:03:45.000Z",
    "durationSeconds": 95,
    "summary": null,
    "recording": null
  }
}
```

| Field | Meaning |
| --- | --- |
| `status` | `END` (talked), `MISSED` or `REJECTED`. |
| `handledBy` | `ai`, `team` or `api`. |
| `summary`, `recording` | Usually not ready yet when the call ends. The summary arrives with `call.summary`. Fetch the recording with [Get a Call](/api-reference/call/get) a minute later. |

## call.summary

The AI finished summarising a call it took. `data` has the same fields as `call.ended`, with `summary` filled in. It usually arrives within a minute of `call.ended`.

## contact.created / contact.updated

A contact was added or changed in AdsEra: by hand, by an import, a form, IndiaMART or the [CRM API](/api-reference/crm/overview). `data` is the contact with its fields flattened: `phone`, `email`, and each attribute by its title, such as `FIRSTNAME` or `CITY`.

<Note>
Someone who messages you on WhatsApp for the first time arrives as `message.new` (with their phone and name), not `contact.created`.
</Note>

## call

This event is for numbers whose calls are answered by your own system ([Call API](/api-reference/call/connect)). It carries the live call signals. To log calls in a CRM, use `call.ended` instead.

## order.created

A customer placed an order through WhatsApp Commerce. `data` is the order.
